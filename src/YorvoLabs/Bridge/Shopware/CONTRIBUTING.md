# Contributing

Development for this package takes place in the [yorvolabs/canary-platform](https://github.com/yorvolabs/canary-platform) monorepo, which includes both `yorvolabs/canary` (core) and `yorvolabs/canary-bridge-shopware` (this package).

Please refer to the [monorepo CONTRIBUTING guide](https://github.com/yorvolabs/canary-platform/blob/main/CONTRIBUTING.md) for setup instructions, test commands, code style requirements, and the PR process.

For bug reports and security vulnerabilities, see [SECURITY.md](https://github.com/yorvolabs/canary-platform/blob/main/SECURITY.md) or open an issue at [github.com/yorvolabs/canary-platform/issues](https://github.com/yorvolabs/canary-platform/issues).
